# Vue3 + Electron 桌面版重构需求文档

## 1. 背景

当前项目由两部分组成：

- 根目录 `main.py`：图片抓取、状态管理、本地图库展示、日期切换。
- `pic_web/main.py`：图片打码编辑、导出、贴图填充、白条文字、ZIP 转 GIF。

现状问题：

- Python + FastAPI + 原生 JS 的功能已经可用，但页面逻辑逐渐变重，前后端边界不清晰。
- 依赖浏览器访问本地服务，不适合做长期桌面端维护。
- 图片管理、文件系统访问、本地目录浏览、本地打开文件这类需求更适合 Electron。
- 打码编辑器交互逻辑复杂，继续堆在原生脚本中维护成本较高。

## 2. 重构目标

将当前项目重构为一个基于 `Vue 3 + Electron` 的桌面应用，目标包括：

- 提供稳定的桌面端入口，无需手动访问本地网页。
- 使用 `Vue 3` 组件化重构 UI 和交互逻辑。
- 使用 `Electron` 直接访问本地文件系统、目录、图片、导出路径。
- 将“抓图管理”和“打码编辑”拆分成清晰模块。
- 在重构阶段尽量复用现有数据目录格式，避免破坏已有 `hot_pic`、`drawer` 等数据。

## 3. 产品定位

这是一个面向个人桌面使用的图片工作台，包含两大核心模块：

1. 抓图与本地图库管理
2. 图片打码与导出编辑

## 4. 用户场景

### 4.1 抓图用户场景

- 用户设置起始页、结束页、过滤标签，启动抓图任务。
- 用户查看实时日志、任务状态、抓取中的新图片。
- 用户浏览本地已下载图库，并按日期切换。
- 用户打开本地图片原文件。
- 用户从图库直接跳转到打码编辑器。

### 4.2 打码用户场景

- 用户从本地图库进入编辑器时，自动带入图片和来源信息。
- 用户在画布中拖拽创建打码区域。
- 用户选择打码方式：马赛克、透明背景文字、贴图填充、显示遮罩。
- 用户编辑透明文字内容、字体、字号、方向。
- 用户使用作者名、角色名快速填入文字。
- 用户导出 PNG，或复制结果图。

## 6. 功能需求

### 6.1 桌面应用框架

- 应用启动后进入单窗口主界面。
- 左侧为功能导航，右侧为内容区。
- 提供两个一级页面：
  - 抓图管理
  - 打码编辑

### 6.2 抓图管理页

- 支持输入起始页、结束页、过滤标签。
- 提供任务操作区：
  - 启动
  - 暂停
  - 继续
  - 停止
- 提供日志区。
- 提供图库区：
  - 最新抓取
  - 本地已下载
- 本地已下载支持：
  - 日期日历选择
  - 上一天 / 下一天
  - 回到今天
  - 区分有图日期和无图日期
- 图片卡片支持：
  - 查看原帖
  - 打开本地文件
  - 跳转到打码编辑

### 6.3 打码编辑页

- 支持从图库带图进入。
- 支持手动选择图片进入。
- 显示来源信息：
  - 作者
  - 角色
  - 原帖链接
- 提供快捷按钮：
  - 作者填入文字
  - 角色填入文字
- 提供打码方式切换：
  - 默认马赛克
  - 透明背景文字
  - 贴图填充
  - 显示遮罩
- 透明背景文字模式支持：
  - 文字
  - 字体
  - 字号
  - 方向
  - 透明度
- 所有打码方式都基于用户拖拽矩形区域，不自动贯穿整图。
- 支持：
  - 移动图层
  - 缩放图层
  - 删除选中
  - 撤销最后一层
  - 清空
  - 适应窗口
  - 实际大小
  - 放大
  - 导出 PNG

## 7. 非功能需求

- Windows 优先兼容
- 保持对现有目录结构兼容：
  - `hot_pic/YYYY-MM-DD`
  - `hot_pic/*/viewer_data.json`
  - `drawer/*`
- 应用需要支持大图编辑的基本流畅度
- 所有本地文件访问通过 Electron `preload` 安全暴露
- 渲染进程不直接开放 Node 全权限

## 9. 技术方案

### 9.1 前端

- Vue 3
- Vite
- Composition API

### 9.2 桌面壳

- Electron
- `main` 进程负责：
  - 窗口创建
  - 本地文件系统访问
  - 目录扫描
  - 图片文件读取
  - 文件保存
  - 打开本地文件
  - 打开外部链接

### 9.3 数据访问

- 通过 `preload` 暴露 `desktopAPI`
- Renderer 只调用白名单方法

### 9.4 数据目录复用

- 本地图库仍使用现有 `hot_pic` 目录
- `viewer_data.json` 继续作为图片元数据来源
- 打码页从图库跳转时通过路由状态或共享状态传递来源信息

## 10. 状态管理建议

按模块拆分：

- `gallery state`
  - 日期列表
  - 当前日期
  - 图片列表
  - 预览图状态
- `editor state`
  - 当前图片
  - 来源信息
  - 图层数组
  - 当前选中图层
  - 画布缩放
- `crawler state`
  - 任务状态
  - 日志
  - 参数表单

## 13. 风险

- Python 抓虫逻辑当前和 FastAPI 状态耦合较深，不能一步无痛迁移。
- Electron 打包后对本地路径和静态资源路径需要单独处理。
- 大图编辑和导出需要避免内存峰值过高。
